# Contributing

This is my personal learning journal, so I'm not looking for feature work — but bug reports,
typo fixes and suggestions are very welcome. Please open an issue first.

[COMMERCIAL-LICENSE.md](COMMERCIAL-LICENSE.md)). To keep that possible, by opening a pull
request you agree that:

- your contribution is your own work, and

  relicense your contribution under the AGPL-3.0 **and** under commercial terms.

If you don't agree, please open an issue describing the change instead of a pull request.

## Development

See [docs/setup.md](docs/setup.md). Before opening a PR, run:

```bash
npm test
npm run check
```
