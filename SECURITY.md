# Security

If you find a security problem (for example a way into the admin area, or a way to see draft
content), **please don't open a public issue**. Report it privately through GitHub's
"Report a vulnerability" button on this repository (Security tab), or via
[kiaramaldonado.com](https://kiaramaldonado.com).

How the site is protected is described in [docs/security.md](docs/security.md).
